# AI Clinical Decision Support System (PS-04)

An AI-powered system to assist doctors by predicting diseases based on
patient symptoms, vitals, and lab results.

## Features
- Disease prediction using ML
- Differential diagnosis
- Diagnostic test recommendations
- Explainable AI

## Tech Stack
- Python
- Flask
- Scikit-learn
- HTML/CSS

## Architecture
User → Web UI → Flask → ML Model → Prediction → Recommendation
