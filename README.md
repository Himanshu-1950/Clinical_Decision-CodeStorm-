# 🏥 AI Clinical Decision Support System  
> PS-04 | An AI-powered tool to assist clinicians with disease prediction, differential diagnosis, and diagnostic test guidance.

---

## 📌 Overview
The **AI Clinical Decision Support System** helps doctors analyze patient symptoms, vitals, and lab values to predict possible diseases and recommend appropriate diagnostic tests.  
Built using **Machine Learning + Flask**, it delivers fast, interactive, and reliable medical decision support.

---

## ✨ Features
- ✔️ Disease Prediction using Machine Learning  
- ✔️ Differential Diagnosis Ranking  
- ✔️ Probabilistic Confidence Scores  
- ✔️ Recommended Diagnostic Tests  
- ✔️ Clean & Modern UI  
- ✔️ Fast & Lightweight Backend (Flask)
